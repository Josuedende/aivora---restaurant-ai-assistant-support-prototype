# AIVORA - Restaurant Operations & Guest Communication

Modern restaurant guest operations web application built with React, Vite, Tailwind CSS, and TypeScript.

## Quick Start in VS Code

1. **Open the project in VS Code**:
   ```bash
   cd aivora-project
   code .
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:3000`

## Available Scripts

- `npm run dev`: Starts the local development server on port 3000.
- `npm run build`: Bundles production assets into `dist/`.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Runs TypeScript type checking.

## Tech Stack

- **React 19**
- **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Lucide React** (icons)
